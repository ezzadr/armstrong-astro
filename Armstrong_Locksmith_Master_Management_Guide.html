2. How to Edit the Site When You Are NOT at the Shop (Remote Mode)

You can manage and update your website from any phone, laptop, iPad, or home computer anywhere in the world without installing any developer tools:

Step 1: Open your browser on any device and go to: 
https://armstronglocksmithinc.com/admin/
Step 2: Click "Log in with GitHub" and authenticate with your GitHub username (ezzadr).
Step 3: In the dashboard, you can:
  • Create New Blog Guides: Click "New Blog Post", write your article using the rich visual editor, add a category badge, and upload photos.
  • Edit Existing Technical Guides: Click any of your 6 existing articles to modify text, update pricing, or refine customer case studies.
  • Manage SEO Metadata: Customize page titles, meta descriptions, and featured image previews directly.
Step 4: Click "Publish". Decap CMS instantly commits the changes to GitHub, which triggers Cloudways to pull and deploy the update live to visitors in seconds!

3. How the Website Was Built (Technical Architecture)

⚡ Astro 5 Framework

Replaced slow WordPress and Elementor PHP database rendering with an ultra-fast, pre-rendered static HTML generator. The entire site is under 70 KB and loads in 107 milliseconds.

☁️ Cloudways Hybrid Stack

Hosted on high-frequency Vultr server (16GB RAM) running Nginx reverse proxy + Apache backend + Varnish edge caching + PHP 8.2 runtime.

📱 Native Twilio SMS Integration

Located at /api/contact.php. When a customer requests a quote, it fires an instant SMS alert to (615) 625-8000 and saves an encrypted backup lead log on the server.

🤖 AI & Generative Engine SEO

Includes complete LocalBusiness schemas, robots.txt whitelist, and /llms.txt standard knowledge base for ChatGPT, Claude, Perplexity, and Apple Intelligence.

4. How to Download & Work on Another Computer (Local Developer Mode)

If you want to set up the project on a new laptop or home PC:

Step 1: Install Node.js (LTS Version from https://nodejs.org) and Git (from https://git-scm.com).
Step 2: Open your Terminal or PowerShell in your desired folder (e.g. C:\Projects\ or Documents) and clone your private repository: 
git clone https://github.com/ezzadr/armstrong-astro.git
cd armstrong-astro
Step 3: Install dependencies: 
npm install
Step 4: Start the local preview server: 
npm run dev
Your local site will immediately be live at http://localhost:4321/ with hot-reloading!
Step 5: Build and deploy changes: 
npm run build
git add .
git commit -m "Describe your update here"
git push origin main
